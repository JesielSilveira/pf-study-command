PF STUDY COMMAND — COMO INICIAR

1. Extraia a pasta "pf-study-command" para a Área de Trabalho.
2. Abra o PowerShell dentro dessa pasta.
3. Execute estes comandos (use npm.cmd para evitar o bloqueio do PowerShell):

   npm.cmd install
   npm.cmd run dev

4. Abra no navegador:
   http://localhost:3000

PARA PARAR:
   Pressione CTRL + C no terminal.

O QUE JÁ ESTÁ PRONTO:
- Painel de preparação para Agente da Polícia Federal.
- Meta diária de 2 horas.
- Cronômetro Pomodoro de 25 minutos.
- Registro manual de sessões concluídas.
- Checklist inicial de disciplinas e conteúdos.
- Filtro por disciplina.
- Anotações salvas automaticamente no navegador.

IMPORTANTE:
O progresso fica salvo no navegador/dispositivo em que você usa o painel.
A lista de conteúdos é um plano-base inicial, não substitui o edital oficial.
